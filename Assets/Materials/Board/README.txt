Halloween Monster Chess Pieces (OBJ)
=====================================

This pack contains 6 stylized low-poly monster chess pieces designed to match a dark Halloween chessboard.

Pieces:
- pawn_rampant.obj         -> small crawling ghoul pawn
- rook_sarcophagus.obj     -> living sarcophagus rook
- knight_spectral_horse.obj-> spectral horse knight
- bishop_plague_priest.obj -> plague-priest bishop
- queen_banshee.obj        -> banshee / spider-queen
- king_lich.obj            -> lich king

Files:
- Each OBJ references materials.mtl in the same folder.
- Units are roughly scaled to fit a 1x1 Unity chess tile. Most pieces are about 0.6 to 0.75 units wide.
- Up axis: Y. Base rests around Y=0.

Unity import tips:
1) Copy the folder into Assets/Art/ChessPieces/
2) Import each OBJ.
3) In the model import settings, set Scale Factor to 1.
4) Create two material variants in Unity:
   - violet necromancy team
   - ember infernal team
5) If needed, use FBX Exporter from Unity Package Manager to export each prefab to FBX.

These are stylized, game-ready concept meshes meant as a stronger monstrous direction than classic chess pieces.
